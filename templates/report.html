Scope & coverage

This report contains the returned Resource Graph data visible to the signed-in user in one selected tenant. It is not proof of a complete tenant inventory. Azure may silently omit resources without read access. Resource Graph supports a subset of management-plane objects, is eventually consistent, and is not an atomic snapshot. Data-plane contents, costs, auditing, and comprehensive RBAC analysis are excluded.

Collection details and subscription status

A successful query can return zero visible rows. Referenced objects absent from the resource table may be embedded subresources, unsupported objects, or outside readable scope; this report does not guess the reason. Names and tags may be confidential.

Architecture diagrams

Diagrams are generated locally on demand. Edges mean observed references or structural containment, not verified traffic, access permissions, or a full application dependency map. Large views are split into pages; all resources remain in the Resources tab.

Editable draw.io files are created in this browser. Open them in draw.io Desktop or the VS Code Draw.io Integration extension; do not upload customer data to web services without approval.

Diagrams are rendered when this tab is opened or a view is selected; none are rendered at page startup.
